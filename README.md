# 圖片批次縮圖工具 v2.8

## v2.3 介面更新

- 桌機版改成左右雙欄
  - 左側：拖曳圖片、縮圖列表、單張調整
  - 右側：批次縮圖設定、處理與下載
- 右側設定區使用 sticky，捲動大量圖片時仍能看到設定與下載按鈕
- 手機與窄螢幕自動回到上下單欄
- 頁首新增明顯版本號 `v2.3`

## 保留 v2.2 功能

- 批次縮圖
- 單張調整
- 自由裁切
- 四邊與四角拉伸裁切框
- 重新拉裁切框
- 1:1、4:3、3:2、16:9、4:5、9:16、A4 直式
- 左轉 / 右轉 90°
- 最終裁切預覽
- 單張直接下載
- 多張 ZIP
- 中文檔名 UTF-8
- 純前端本機處理，不上傳圖片


## v2.4 介面調整

- 桌機版改為 ①圖片、②批次縮圖設定、③處理與下載三欄並排。
- 平板與手機自動改為較適合螢幕寬度的排列。
- 保留既有圖片處理、裁切、旋轉與下載功能。

## v2.5 介面調整

- 「批次縮圖設定」增加提示：不想調整可直接到第 3 欄開始縮圖。
- 網站圖片 / Email / 自訂改為每列 2 個。
- 只限制像素 / 只限制容量 / 同時限制改為每列 2 個。

## v2.6 介面調整

- 「不想調整設定，可直接到右邊按開始縮圖」改為較大紅色粗體提示。
- 第 2 欄「批次縮圖設定」加寬。
- 微調三欄比例，讓設定選項更好閱讀。

## v2.8 手機版介面

- 手機版改為 mobile-first 排版。
- 縮短圖片拖曳區高度，減少大面積空白。
- 圖片縮圖手機維持兩欄。
- 快速模式與限制條件維持兩個一排。
- 處理摘要改為三個小卡並排。
- 處理與下載按鈕全寬。
- 單張圖片編輯改為近全螢幕操作。
- 編輯視窗的標題與底部操作按鈕在手機上保持較容易操作的位置。


## v2.8 裁切模式

- 「只擷取部分」可與固定比例同時使用。
- 比例固定時，裁切框仍可自由移動與縮放。
